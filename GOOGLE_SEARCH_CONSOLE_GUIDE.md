# Google Search Console Integration Guide

## Pengenalan
File ini menjelaskan cara mengintegrasikan website Anda dengan Google Search Console untuk SEO yang lebih baik.

---

## 3 Metode Verifikasi Google Search Console

### **Metode 1: HTML File Verification (✅ RECOMMENDED)**

#### Langkah-langkah:
1. **Buka Google Search Console**: https://search.google.com/search-console
2. **Klik "Add property"** → Masukkan domain Anda (contoh: `https://larasena.com`)
3. **Pilih "HTML file"** sebagai metode verifikasi
4. **Download file verification** → Nama file akan seperti `googleXXXXXXXXXXXXXXXX.html`
5. **Simpan file di folder `public/`** di project Anda
6. **Klik "Verify"** di Google Search Console

```
public/
├── index.php
├── robots.txt
├── googleABCD1234EFGH5678.html  ← File verification dari Google
└── ...
```

**Route yang menangani:**
```
GET /googleABCD1234EFGH5678.html
```

Route ini otomatis ter-handle oleh controller:
```php
Route::get('/{filename}', [GoogleSearchConsoleController::class, 'verifyHtml'])
    ->where('filename', 'google[a-f0-9]+\.html');
```

---

### **Metode 2: Meta Tag Verification**

#### Langkah-langkah:
1. **Buka Google Search Console** → Pilih "Meta tag" sebagai metode verifikasi
2. **Copy meta tag** yang diberikan, contoh:
   ```html
   <meta name="google-site-verification" content="XXXXXXXXXXXXXXXXXXXXXX" />
   ```
3. **Simpan content di `.env`:**
   ```env
   GOOGLE_SEARCH_CONSOLE_META=XXXXXXXXXXXXXXXXXXXXXX
   ```
4. **Di layout/template utama Anda** (contoh: `resources/views/app.blade.php`), tambahkan:
   ```html
   <head>
       <!-- Google Search Console Meta Verification -->
       @if(env('GOOGLE_SEARCH_CONSOLE_META'))
           <meta name="google-site-verification" content="{{ env('GOOGLE_SEARCH_CONSOLE_META') }}" />
       @endif
       <!-- ... meta tags lainnya -->
   </head>
   ```
5. **Klik "Verify"** di Google Search Console

**Endpoint untuk validasi:**
```
GET /api/google-meta-verification
```

Response akan menunjukkan meta tag yang dikonfigurasi:
```json
{
    "meta_content": "XXXXXXXXXXXXXXXXXXXXXX",
    "meta_tag": "<meta name=\"google-site-verification\" content=\"XXXXXXXXXXXXXXXXXXXXXX\" />"
}
```

---

### **Metode 3: Domain Name Provider Verification**

Verifikasi melalui DNS record di registrar domain (GoDaddy, Namecheap, dll):
1. Buka Google Search Console → Pilih "DNS record"
2. Copy TXT record yang diberikan
3. Masuk ke dashboard domain registrar Anda
4. Tambahkan TXT record di DNS settings
5. Klik "Verify" di Google Search Console

(Controller tidak perlu untuk metode ini)

## Robots.txt

Robots.txt sudah dihandle oleh `RobotsController`:

```
GET /robots.txt
```

**File ini mengatur:**
- ✅ URL mana saja yang bisa di-crawl
- ❌ URL yang harus di-exclude (admin, private, dll)
- 🗺️ Lokasi sitemap
- ⏱️ Crawl delay

**Current robots.txt rules:**
```txt
User-agent: *
Allow: /
Disallow: /admin*
Disallow: /konveksi-dashboard
Disallow: /storage/
Disallow: /vendor/
Allow: /storage/generated_batik/
Crawl-delay: 1

Sitemap: https://larasena.com/sitemap.xml
```

## Sitemap

Sitemap sudah ada di `SitemapController`:

GET /sitemap.xml

Ini berisi semua URL penting dari website Anda untuk memudahkan Google mengindex.

## Setup Checklist

### 1️⃣ **Pilih Metode Verifikasi**
- [ ] HTML File (Metode 1) - Paling mudah
- [ ] Meta Tag (Metode 2) - Jika tidak bisa upload file
- [ ] DNS Record (Metode 3) - Jika prefer di DNS

### 2️⃣ **Konfigurasi Environment**
Edit `.env`:
```env
# Jika menggunakan Meta Tag Verification
GOOGLE_SEARCH_CONSOLE_META=your_verification_code_here
```

### 3️⃣ **Update Layout (jika Meta Tag)**
Edit `resources/views/app.blade.php` atau file layout utama:
```html
<head>
    @if(env('GOOGLE_SEARCH_CONSOLE_META'))
        <meta name="google-site-verification" content="{{ env('GOOGLE_SEARCH_CONSOLE_META') }}" />
    @endif
</head>
```

### 4️⃣ **Test Routes**
```bash
# Cek Robots.txt
curl https://larasena.com/robots.txt

# Cek Sitemap
curl https://larasena.com/sitemap.xml

# Test Meta Tag endpoint
curl https://larasena.com/api/google-meta-verification
```

### 5️⃣ **Submit ke Google Search Console**
1. Buka https://search.google.com/search-console
2. Tambahkan property → Verify
3. Tunggu ~24-48 jam untuk crawling dimulai
4. Pergi ke **Sitemaps** → Submit `/sitemap.xml`

## URL Summary

| Route | Purpose |
|-------|---------|
| `GET /sitemap.xml` | XML Sitemap untuk crawling |
| `GET /robots.txt` | Robots rules untuk crawlers |
| `GET /googleXXXXX.html` | HTML file verification (jika Metode 1) |
| `GET /api/google-meta-verification` | Get meta tag (helper API) |
| `POST /api/google-submit-sitemap` | Info tentang submit sitemap |

## Troubleshooting

### ❌ "Verification file not found"
- Pastikan file `googleXXXXXXXX.html` ada di folder `public/`
- Filename harus persis sesuai dengan yang Google berikan
- Check permission file

### ❌ "Meta tag tidak terdeteksi"
- Pastikan `GOOGLE_SEARCH_CONSOLE_META` di `.env` benar
- Clear browser cache
- Check HTML source dengan inspect element

### ❌ "Sitemap tidak ter-update"
- Robots.txt sudah point ke `/sitemap.xml` ✅
- Submit manual di Google Search Console
- Tunggu Google re-crawl (24-48 jam)
